"මට කිසිදු රැකියා පළපුරුද්දක් නැහැ. මම කොහොමද CV එකක් හදන්නේ?" — මෙය ශ්‍රී ලංකාවේ විශ්වවිද්‍යාල, උසස් අධ්‍යාපන ආයතන වලින් පිටවන බොහෝ සිසුන් (Fresh Graduates & Undergraduates) නිතරම අසන ප්‍රශ්නයකි.

Recruiters ලා ඇත්තටම අපේක්ෂා කරන්නේ කුමක්ද?

කිසිදු Hiring Manager කෙනෙකු හෝ Recruiter කෙනෙකු Intern කෙනෙකුගෙන් හෝ Fresher කෙනෙකුගෙන් වසර 5ක කර්මාන්ත පළපුරුද්දක් බලාපොරොත්තු නොවේ. ඔවුන් බලන්නේ: ඔබට මූලික තාක්ෂණික පදනම තිබේද? ඔබ සැබෑ Projects හදා තිබේද? සහ ඔබ ඉක්මනින් ඉගෙන ගැනීමට කැමති කෙනෙක්ද (Willingness to Learn)? යන්නයි.

ඔබට රැකියා පළපුරුද්දක් (Work Experience) නොතිබුණද, නිවැරදි ATS-Friendly Single-Column Format එකක් භාවිතා කරමින් ප්‍රමුඛ පෙළේ ආයතන වලින් සම්මුඛ පරීක්ෂණ කැඳවීම් (Interview Calls) ලබාගන්නා නිවැරදි ක්‍රමවේදය මෙන්න:

1. Fresher / Intern CV එකක තිබිය යුතු නිවැරදි අනුපිළිවෙල (Hierarchy)

පළපුරුදු වෘත්තිකයින්ගේ CV එකක මුලින්ම යන්නේ Work Experience ය. නමුත් ඔබ Fresher කෙනෙකු නම්, ඔබේ ප්‍රබලතම වත්කම වන්නේ ඔබේ Education, Technical Skills, සහ Academic Projects ය. ඔබේ CV එක පහත අනුපිළිවෙලට සකස් විය යුතුය:

  1. Contact Header & Live Links: නම, දුරකථන අංකය, Professional Email, LinkedIn, GitHub, සහ Live Portfolio Link.
  2. Education (අධ්‍යාපනය): උපාධිය (Degree / HND), විශ්වවිද්‍යාලය, අපේක්ෂිත වසර, සහ GPA අගය (3.0 ට වැඩි නම්).
  3. Technical Skills (තාක්ෂණික කුසලතා): Languages, Frameworks, Developer Tools, සහ Databases.
  4. Projects (ව්‍යාපෘති - ඔබේ CV එකේ වැදගත්ම කොටස!): විශ්වවිද්‍යාල ව්‍යාපෘති, Capstone Projects, සහ Personal Projects.
  5. Certifications & Hackathons: අන්තර්ජාල පාඨමාලා (Coursera, Udemy, AWS) සහ Hackathon ජයග්‍රහණ.
  6. Leadership & Extracurricular: Rotaract, AIESEC, ශිෂ්‍ය සංගම් හෝ ක්‍රීඩා නායකත්ව.

2. පළපුරුද්දක් වෙනුවට Projects ලියන නිවැරදි ක්‍රමය (Google X-Y-Z Formula)

Fresher කෙනෙකුගේ CV එකක් තීරණය වන්නේ ඔහු කර ඇති Projects වල ගුණාත්මකභාවය මතයි. බොහෝ සිසුන් "Final Year Project: Built an E-Commerce Website using PHP" ලෙස එක් පේළියකින් ලියයි. එයින් Recruiter ට ඔබේ හැකියාව තේරුම් ගත නොහැක.

සෑම Project එකක් සඳහාම Bullet Points 2-3ක් ලියන්න. එහිදී ඔබ භාවිතා කළ Tech Stack එක, විසඳූ ගැටලුව, සහ ප්‍රතිඵලය දක්වන්න:

❌ දුර්වල විස්තරයක්:

"Developed an online blood bank management system using React and Node.js for university final project."

✅ ප්‍රබල ATS විස්තරයක්:

"Architected full-stack Blood Bank web app using React, Node.js, and MongoDB; integrated JWT authentication and automated email alerts, reducing donor match time by 35% during campus pilot testing."

හැකි සෑම විටම ඔබගේ Projects වල GitHub Repository Link සහ Live Demo URL එක ඇතුළත් කරන්න. Recruiter ට ක්ලික් කර බැලිය හැකි Live Project එකක් තිබීම ඔබව අනෙක් තරඟකරුවන් 500 දෙනාගෙන්ම ඉදිරියට ගෙන යයි!

3. Technical Skills ලැයිස්තුගත කිරීමේ රහස

Skills කොටසේ "Hard Worker", "Good Communicator", "Fast Learner" වැනි පොදු වචන දැමීමෙන් වළකින්න. මේවා Soft Skills වන අතර ඒවා පෙන්විය යුත්තේ ඔබේ Project විස්තර තුළිනි.

ATS Scanner එකක් කියවන්නේ නිශ්චිත තාක්ෂණික පද (Hard Keywords) ය. උදාහරණයක් ලෙස:

  • Programming Languages: Java, Python, TypeScript, JavaScript, C#
  • Frontend Technologies: React, HTML5, CSS3, Tailwind CSS, Next.js
  • Backend & Frameworks: Node.js, Express, Spring Boot, FastAPI
  • Databases: MySQL, PostgreSQL, MongoDB, Redis
  • Tools & Platforms: Git, GitHub, Docker, Postman, Linux, VS Code

4. ලංකාවේ Freshers ලා සහ Interns ලා කරන බරපතල වැරදි 5ක්

1. Objective Statement එකක් දැමීම

"To obtain a challenging position in a prestigious organization where I can enhance my skills..." — මෙම පරණ පාසල් Objective වාක්‍ය කිසිවෙකු කියවන්නේ නැත. ඒ වෙනුවට Professional Summary එකක් ලියන්න (උදා: "Final-year Software Engineering undergraduate skilled in React and Node.js with 3 full-stack production projects...").

2. Canva වල තීරු දෙකේ (Two-Column) මෝස්තර තෝරාගැනීම

ලස්සන වුවද, Graphics සහ තීරු දෙකේ මෝස්තර ATS මෘදුකාංග මඟින් ප්‍රතික්ෂේප කරයි. මේ පිළිබඳ සම්පූර්ණ විස්තරයක් අපගේ CV එකක් Reject වන ප්‍රධාන වැරදි 10 ලිපියෙන් කියවන්න.

3. පාසල් විභාග විස්තර ඕනෑවට වඩා දැමීම

ඔබ විශ්වවිද්‍යාල උපාධියක් හෝ ඩිප්ලෝමාවක් හදාරන්නේ නම්, O/L විභාගයේ විෂයන් 9ම ලකුණු සහිතව දැමීම අනවශ්‍යයි. A/L ප්‍රතිඵල සහ පාසල පමණක් කෙටියෙන් සඳහන් කිරීම ප්‍රමාණවත්ය.

4. "References Available Upon Request" කියා ලිවීම

මෙය පිටුවේ ඉඩ නාස්ති කරන යල්පැනගිය වාක්‍යයකි. අවශ්‍ය නම් සමාගම විසින් References ඉල්ලා සිටිනු ඇත. ඒ ඉඩෙහි තවත් හොඳ Project එකක් ලියන්න.

5. CV එක පිටු 2කට වඩා දිගු කිරීම

කිසිදු පළපුරුද්දක් නැති ශිෂ්‍යයෙකුගේ CV එකක් පිටු 1ක් (One-Page) විය යුතුය. පිටු 2ක් හෝ 3ක් දිගු කිරීමෙන් වැදගත් දත්ත මඟහැරේ.

නිතර අසන ප්‍රශ්න (FAQ) - Freshers & Interns CV

1. මගේ GPA එක අඩු නම් මම එය CV එකට දැමිය යුතුද?

ඔබගේ GPA අගය 3.0 ට වඩා අඩු නම්, එය CV එකෙහි සඳහන් නොකර සිටීම වඩාත් යෝග්‍ය වේ. ඒ වෙනුවට ඔබ කළ Projects සහ Practical Skills ඉහළින් පෙන්වන්න.

"How do I write a resume when I have zero work experience?" — this is the number one hurdle every university student, recent graduate, and career changer faces when entering the professional job market.

What Recruiters Actually Look For in Interns:

Hiring managers at top tech firms and global corporations do not expect five years of enterprise experience from an intern or entry-level candidate. They evaluate three core pillars: solid theoretical fundamentals, proven hands-on project work, and a demonstrated hunger to learn.

1. The Ideal Structure of an Entry-Level ATS Resume

Experienced professionals place work experience at the top. For a fresher, your strongest value drivers are your education, technical competencies, and academic/personal projects. Organize your single-column resume in this exact order:

  1. Header & Digital Presence: Full name, verified contact info, professional email, LinkedIn URL, GitHub profile, and custom live portfolio.
  2. Education: Degree title, University / Institution, Graduation Year, and GPA (if 3.2+).
  3. Technical Skills: Clearly categorized (Languages, Frameworks, Developer Tools, Databases).
  4. Projects: 2 to 3 featured academic, capstone, or personal full-stack projects with live demo URLs.
  5. Certifications & Competitions: Industry certifications (AWS, Google Cloud, Meta) and Hackathon achievements.
  6. Extracurricular Leadership: Club leadership, tech community volunteering, or sports achievements.
