වත්මන් අධික තරඟකාරී රැකියා වෙළඳපොළ තුළ එක් Software Engineer, DevOps, හෝ Tech / Corporate ඇබෑර්තුවක් සඳහා පළමු පැය 24 තුළ අයදුම්පත් 500කට වඩා ලැබේ. සමාගම් වලට මේ සියලුම CV අතින් කියවීමට නොහැකි බැවින්, ඔවුන් Applicant Tracking Systems (ATS) නම් වූ ස්වයංක්‍රීය මෘදුකාංග (Workday, Greenhouse, Lever, Taleo) භාවිතා කරයි.

ඔබ දැනගත යුතු කටුක සත්‍යය:

Recruiter කෙනෙකු සාමාන්‍යයෙන් එක් CV එකක් බැලීමට වැය කරන්නේ තත්පර 6ක් පමණි. නමුත් ඊටත් පෙර, ලැබෙන CV වලින් 75%ක්ම මිනිස් ඇසකටවත් නොගොස් ATS Scanner එක මඟින් Auto-Reject වේ. ඔබේ CV එකේ කොතෙක් පළපුරුද්ද තිබුණත්, ATS පද්ධතියට එය කියවාගත නොහැකි නම් සම්මුඛ පරීක්ෂණ (Interview) ඇරයුම් කිසිදා නොලැබේ.

ඔබගේ රැකියා අයදුම්පත පළමු තත්පර 6 තුළ Reject වීමට හේතුවන ප්‍රධානතම වැරදි 10ක්, සැබෑ උදාහරණ (Before vs After) සහ ඒවා නිවැරදි කරගන්නා ආකාරය පහතින් විස්තර කෙරේ.

වැරැද්ද 1: Two-Column සහ Multi-Column Layouts (තීරු දෙකේ මෝස්තර)

ගැටලුව: බොහෝ දෙනෙක් Canva හෝ Graphic Design වෙබ් අඩවි මඟින් වම්පස Sidebar එකක් සහිත ලස්සන Two-Column Templates තෝරා ගනිති. නමුත් ATS Scanners කියවන්නේ ඉහළ සිට පහළට සහ වමේ සිට දකුණට සම්පූර්ණ තිරස් රේඛාවක් ලෙසයි.

❌ වැරදි ක්‍රමය (Two Columns)

වම් තීරුවේ "Skills: Python, React" ද, දකුණු තීරුවේ "Experience: Senior Dev at ABC" ද ඇති විට, ATS එය කියවන්නේ "Skills: Python Experience: Senior Dev React at ABC" ලෙස අවුල් ජාලාවක් වශයෙනි.

✅ නිවැරදි විසඳුම (Single-Column)

සැමවිටම පිරිසිදු තනි තීරුවේ (Single-Column) සිරස් ධූරාවලියක් භාවිතා කරන්න. Contact Info → Summary → Skills → Experience → Education පිළිවෙලට තබන්න.

ඔබට තනි තීරුවේ පිරිසිදු layout එකක් සාදාගැනීමට අවශ්‍ය නම් අපගේ 2026 දී ATS-Friendly CV එකක් හදන සම්පූර්ණ මාර්ගෝපදේශය කියවන්න.

නොමිලේ ATS Scanner පරීක්ෂාව

ඔබේ CV එකෙහි Formatting වැරදි තිබේදැයි බලන්න

DreemFolio AI වෙත ඔබගේ CV එක Upload කර ATS මඟින් ඔබගේ දත්ත නිවැරදිව කියවනවාදැයි තත්පර 10කින් පරීක්ෂා කරගන්න.

නොමිලේ ATS ලකුණු බලන්න

වැරැද්ද 2: Graphical Skill Ratings සහ Progress Bars (තාරකා සහ තීරු)

ගැටලුව: Photoshop හෝ Canva templates වල බහුලව දකින "Java ★★★★☆" හෝ "Python 85%" වැනි Progress Bars සහ Stars දැමීම.

ATS කියවන්නේ අකුරු පමණි (Plain Text). ග්‍රැෆික්ස්, තරු හෝ පාට තීරු ATS එකට සම්පූර්ණයෙන්ම අදෘශ්‍යමාන වේ (Zero visibility). මීට අමතරව Senior Hiring Managers ලා මෙවැනි ප්‍රතිශත දැකීම ආධුනික සහ මවාපෑමක් ලෙස සලකයි (Python 85% කියන්නේ කුමක්දැයි මැනිය නොහැක).

විසඳුම: Skills කාණ්ඩ අනුව වර්ග කරන්න:

  • Languages: TypeScript, Python, Java, SQL
  • Frameworks & Libraries: React, Node.js, FastAPI, Next.js, Tailwind CSS
  • Cloud & DevOps: AWS (EC2, S3), Docker, Kubernetes, GitHub Actions
  • Databases: PostgreSQL, Redis, MongoDB

වැරැද්ද 3: විසිතුරු සහ සම්මත නොවන Section Headers

සමහරු තම CV එක විශේෂ කිරීමට සිතා "My Professional Voyage", "Where I've Been", හෝ "Skills Arsenal" වැනි විසිතුරු වචන භාවිතා කරති.

විසඳුම: ATS Parsing Algorithms පුහුණු කර ඇත්තේ සම්මත මාතෘකා කියවීමටයි. සැමවිටම පහත සම්මත ශීර්ෂ පාඨ (H2 Headings) පමණක් යොදන්න:

  • Work Experience හෝ Professional Experience
  • Education
  • Technical Skills
  • Projects හෝ Key Projects
  • Certifications

වැරැද්ද 4: Scanned Image PDFs සහ Canva Flattened Exports

ගැටලුව: ඔබගේ CV එක Canva හෝ Illustrator මඟින් Export කිරීමේදී සමහරවිට එය Export වන්නේ Flattened Graphic Image එකක් ලෙසයි. එනම් පිටුව තුළ ඇත්තේ අකුරු නොව පින්තූරයකි.

ස්වයං පරීක්ෂාව (Self-Check Test): ඔබගේ PDF එක විවෘත කර, Mouse Cursor එක මඟින් අකුරු Highlight කර Ctrl + C (Copy) කර Notepad එකකට Ctrl + V (Paste) කිරීමට උත්සාහ කරන්න. අකුරු Copy කරගත නොහැකි නම්, ATS එකටද කිසිදු අකුරක් කියවිය නොහැක. එවිට ඔබේ Match Score එක 0% වේ!

විසඳුම: සැමවිටම Native Text Vector PDF format එකෙන් CV එක Export කරන්න. DreemFolio AI Builder මඟින් සකසන සෑම PDF එකක්ම 100% Vector Text Engine එකකින් නිපදවනු ලබයි.

වැරැද්ද 5: Job Description එකේ ඇති Keywords අඩංගු නොවීම (Keyword Mismatch)

සෑම රැකියා දැන්වීමකම (Job Description) අවශ්‍ය නිශ්චිත කුසලතා ලැයිස්තුගත කර ඇත. ATS එක එම Job Description එකෙහි ඇති Keywords සහ ඔබගේ CV එකෙහි ඇති වචන අතර ප්‍රතිශතය සංසන්දනය කරයි.

❌ ඔබ ලියා ඇත්තේ: "Experience in Relational Databases and Containerization"

✅ සමාගම ඉල්ලා ඇත්තේ: "PostgreSQL, Docker, Kubernetes"

මෙහිදී ඔබ Relational DB ගැන දැන සිටියත්, PostgreSQL යන නිශ්චිත keyword එක ඔබේ CV එකේ නොමැති නම් ATS Scanner එක ඔබට ලකුණු 0ක් ලබා දෙයි.

වැරැද්ද 6: ප්‍රතිඵල සහ සංඛ්‍යා (Metrics) නොමැති දුර්වල Bullet Points

බොහෝ CV වල රැකියා පළපුරුද්ද යටතේ ලියා ඇත්තේ තමන් කළ දෛනික කාර්යයන් (Job Responsibilities) පමණි:

❌ දුර්වල විස්තරයක්:

"Responsible for database maintenance and writing backend APIs."

✅ Google X-Y-Z ක්‍රමය:

"Optimized PostgreSQL queries and rebuilt 12 backend APIs using FastAPI, reducing database response latency by 42% for 50,000+ active users."

සැමවිටම ප්‍රතිශත (%), පරිශීලක සංඛ්‍යා, වේලාව ඉතිරි කිරීම, හෝ ආදායම් වර්ධනය සංඛ්‍යාත්මකව දක්වන්න.

වැරැද්ද 7: Contact Info ලේඛනයේ Header/Footer තුළ සිරවීම

Microsoft Word හෝ Google Docs ලේඛනයක ඉහළ සහ පහළ ඇති Header/Footer කොටස් බොහෝ ATS පද්ධති මඟින් ස්වයංක්‍රීයව කපා හරිනු ලැබේ (Striped out to save space). ඔබගේ Email ලිපිනය, දුරකථන අංකය හෝ LinkedIn URL එක Header එක තුළ තිබුණහොත්, Recruiter ට ඔබව සම්බන්ධ කරගැනීමට තොරතුරු නොමැති වේ.
